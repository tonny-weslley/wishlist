Backup no JSONBin

Salvar e recuperar o cadastro completo.

O envio inclui listas, ofertas, notas pessoais, metas, orçamento e histórico. O Bin deve ser privado. A chave é enviada somente ao JSONBin em cabeçalho HTTPS e não entra no backup nem no código publicado.

Sem marcar a opção, a chave fica só nesta aba. Lembrar guarda a chave sem criptografia no navegador. Use Access Key com permissões necessárias e nunca publique a chave no GitHub Pages.

Configure a chave e o ID ou crie um Bin privado.

Conferir cópia remota

Mesclar adiciona os dados remotos, reutilizando URLs locais. Restaurar substitui o cadastro local após baixar uma cópia dele. Usar local substitui o remoto após baixar a cópia anterior.

Não há consultas periódicas. Para consultar outro dispositivo, use Recuperar. Alterações remotas são conferidas antes do envio; a API não oferece aqui uma gravação condicional atômica. Evite edições simultâneas em dispositivos diferentes. Envios pedem histórico de versões.

Adicionar pela extensão

Abra o produto no Firefox ou Chrome e clique na extensão Wishlist. Capture a página, confira o valor total e envie para cá.

Para instalar: abra about:debugging no Firefox → Este Firefox → Carregar extensão temporária → selecione extenssion/firefox/manifest.json. A instalação temporária precisa ser repetida após reiniciar o Firefox. No Chrome: abra chrome://extensions, ative o modo de desenvolvedor, clique em Carregar sem compactação e selecione extenssion/chrome.

Importar backup continua disponível para restaurar seus dados.
